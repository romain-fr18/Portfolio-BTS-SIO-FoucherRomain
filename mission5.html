Conception et Réalisation d'un Site Web

Parmi les différentes missions à effectuer, la création d'un site web vitrine était demandée. Son but principal était de travailler avec les langages de programmation HTML et CSS pour modeler un site web sur le thème de notre choix. La particularité de ce site était qu'il devait être visible via un référencement et un hébergement.

📋 Cahier des charges
  • Manier les langages HTML et CSS
  • Site web vitrine sur le thème choisi
  • Recherches sur hébergeur et référencement
  • Mise en place de l'hébergement
  • Mise en place du référencement
🛠️ Tâches effectuées
  • Site web vitrine — parodie du site "Marmiton"
  • Application HTML, CSS et JavaScript
  • Hébergement sur GitHub Pages
  • Référencement via Google Search Console
Points Forts
  • ✅ Meilleure compréhension des langages de programmation
  • ✅ Base de création de site pour plus tard
  • ✅ Notion de travail en binôme
Points Faibles
  • ⚠️ Manier les langages avec précision
  • ⚠️ Aide avec IA sur points difficiles
  • ⚠️ Fournir un site avec une interface correcte
Avis Personnel

Même si mon choix d'orientation se portait vers un côté "Réseau", la pratique portée sur un site web m'a vraiment plu. Manier les outils de programmation pour créer son site web montre vraiment comment fonctionne un site. C'était quelque chose de nouveau pour moi, et l'avoir fait avec un camarade tout en voyant le résultat final est vraiment quelque chose de marquant.
